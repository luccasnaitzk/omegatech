### PASSO 2: Conecte seu Repositório Local ao GitHub

Copie e execute EXATAMENTE estes comandos no Terminal (PowerShell ou CMD):

```powershell
cd "c:\Users\dobes\OneDrive\Área de Trabalho\Projeto_OmegaTech\Projeto_OmegaTech"
```

⚠️ **IMPORTANTE**: Substitua `SEU_USUARIO` pelo seu usuário do GitHub!

### PASSO 3: Autentique-se no GitHub

Quando o Terminal pedir Username e Password:
- **Username**: Seu usuário do GitHub (ex: joaosilva)
- **Password**: Seu Personal Access Token (não é a senha do GitHub!)

#### Como Gerar um Token:

1. Acesse https://github.com/settings/tokens
2. Clique em "Generate new token"
3. Dê um nome: "OmegaTech Push"
4. Selecione: `repo` (acesso completo)
5. Limiar de expiração: 90 dias (ou escolha outra)
6. Clique em "Generate token"
7. **COPIE o token** (ele não fica disponível depois!)
8. Cole o token como password no Terminal

## ❓ Erros Comuns

| Erro | Solução |
|------|---------|
| "fatal: pathspec 'origin' does not match any file" | Você já rodou `git remote add origin`. Use `git remote set-url origin https://...` para substituir |
| "401 Unauthorized" | Token inválido ou expirado. Gere um novo em GitHub settings |
| "already exists" | Repositório já criado. Delete ou use outro nome |
| Nada acontece no Terminal | Rode `git push -u origin main` novamente |
